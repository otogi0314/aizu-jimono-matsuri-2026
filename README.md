# 会津じものまつり 2026 公式サイト

会津地域のイベント「会津じものまつり」の公式サイトです。OMJでのインターンとして、実装と公開を担当しました。

公開サイト: https://aizujimono.jp

> 公開中のサイトは、引き継ぎ後に別の担当者が更新を続けています。このリポジトリは、私の担当範囲の最終版（2026-10-20時点）です。

## 概要

- **目的**: 来場者への情報発信と、出店者・体験ブース・協賛企業の募集
- **担当**: 実装、SEO対応、Cloudflareへの公開、引き継ぎ資料の作成

## 工夫した点

- **非エンジニアでも更新できる構成**: 文章や協賛企業は `app/page.tsx` のデータを書き換えるだけで更新できます。手順は `EDIT_GUIDE.md` にまとめました。
- **募集をGoogleフォームに集約**: 募集・申込はすべてフォームへのリンクにして、運営側が管理しやすくしました。
- **検索・共有への配慮**: メタ情報、OGP、構造化データ、`sitemap`、`robots`、`www` から本体ドメインへのリダイレクトを実装しました。
- **FAQと協賛企業ロゴ**: 来場者と協賛企業が必要な情報を見つけやすくしました。
- **自動テスト**: 描画されたHTMLを確認するテスト（`tests/`）を用意しました。

## 技術スタック

- [vinext](https://github.com/cloudflare/vinext)（Next.js互換）、React 19、Tailwind CSS 4、TypeScript
- Cloudflare Workers（ホスティング、画像最適化、リダイレクト）
- Node.js 標準のテストランナー（`node --test`）

## 主なファイル

| ファイル | 内容 |
|---|---|
| `app/page.tsx` | ページ本体。文章、日時、募集、協賛企業、FAQ |
| `app/layout.tsx` | タイトル、説明文、OGP、構造化データ |
| `app/MenuHeader.tsx` | ハンバーガーメニュー |
| `app/globals.css` | 色、余白、アニメーション |
| `public/` | 画像、協賛企業ロゴ |
| `worker/index.ts` | `www` からのリダイレクトと画像最適化 |
| `vite.config.ts` | ビルドとCloudflareの設定 |
| `EDIT_GUIDE.md` | 非エンジニア向けの編集手順 |

## 手元で動かす

Node.js 22.13 以上が必要です。

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # ビルドして自動テスト
```

公開（`npm run deploy:cloudflare`）には、公開先Cloudflareアカウントの権限が必要なため、このリポジトリだけでは実行できません。
